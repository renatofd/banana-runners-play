# Banana Runners

Playable build of **Banana Runners**, a jungle endless runner for web and mobile (Phaser, WebGL).

**Play:** https://renatofd.github.io/banana-runners-play/

Controls: tap / Space / ↑ to jump (tap again in the air for a double jump), swipe → / → to roll, swipe ↓ / ↓ to drop fast.

This repository contains only the compiled game, not the source code.
